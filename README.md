# appdaemon-dashboards-for-ha
Dashboard configuration for Home Assistant in AppDaemon
The individual dashboards combine to form a comprehensive control panel; I use it on a touchscreen running Touchkio.
Created based on the AppDaemon/GitHub documentation; some adjustments/updates were necessary, but everything works (you will need to use your own entities).
- Weather panel with map
- Home Assistant panel
- Music Assistant panel
- Main panel with player
- Camera panel
- 5 basic skins
- etc
